Bougainville keyboard
=====================

© 2026, SIL PNG

Version 1.3

Description
-----------

A keyboard for Rapoisi, Halia, Tinputz, Terei, Sibe, Petats and Naasioi (Bougainville, Papua New Guinea), with extra characters for phonology work.

Supported Platforms
-------------------
 * Windows
 * macOS
 * Linux
 * Web
 * iPhone
 * iPad
 * Android phone
 * Android tablet
 * Mobile devices
 * Desktop devices
 * Tablet devices
